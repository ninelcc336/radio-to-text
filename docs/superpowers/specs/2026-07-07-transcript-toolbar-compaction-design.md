# 文本产物工具栏压缩设计

## 背景

当前“文本产物”区域已经具备：

- 文本版本切换
- 过滤切换
- 导出能力
- 片段级审核动作

但界面上仍有两个明显问题：

- 顶部工具按钮占用空间过大，信息密度偏低
- `确认 / 修正` 常驻会让片段列表显得拥挤，影响长文本浏览

本次迭代目标是提升空间利用率和视觉层次，不改变现有核心功能。

## 目标

1. 压缩顶部工具区占用空间
2. 保留清晰的功能分层
3. 让片段审核动作更隐形，只在需要时出现
4. 不增加额外点击成本到影响效率的程度

## 非目标

- 不删减现有功能
- 不修改后端协议
- 不变更审核保存逻辑
- 不增加新的导出格式
- 不重做整体视觉风格

## 方案选择

### 方案 A：导出收进 dropdown，片段操作 hover 出现

顶部仅保留常用视图切换，把导出折叠成一个单独入口。

- 顶部常驻：
  - `清洗 / 原始`
  - `全部 / 重点 / 未处理`
  - `未处理 X`
- 单独保留一个 `导出` 按钮
- 点击 `导出` 后展开 dropdown：
  - `复制文本`
  - `导出 TXT`
  - `导出 Markdown`
- 片段级 `确认 / 修正` 默认隐藏，仅在 hover 片段时出现

优点：

- 最省空间
- 工具区职责清楚
- 列表视觉更干净

缺点：

- 需要实现 dropdown 的开关与关闭逻辑

### 方案 B：按钮继续常驻，但缩成更小尺寸

保留现有结构，只压缩按钮尺寸和文案。

优点：

- 改动小

缺点：

- 只能缓解，不能真正解决工具区拥挤问题

### 方案 C：把导出和查看都折叠

优点：

- 节省最多空间

缺点：

- 操作路径变长，不适合工具型桌面应用

### 推荐方案

采用方案 A。

原因：

- 用户已明确接受 `导出` 用 dropdown 形式
- 用户希望 `确认 / 修正` 只在 hover 时出现
- 该方案可以在不删功能的前提下，把顶部和片段两处空间同时收紧

## 页面结构设计

### 顶部工具区

顶部从“两行多按钮”改成“一条主工具栏”：

- 左侧：查看切换
  - `清洗`
  - `原始`
  - `全部`
  - `重点`
  - `未处理`
- 中间或靠右：`未处理 X`
- 最右侧：`导出`

按钮文案使用短标签，依靠 tooltip 补足完整语义。

### 导出 dropdown

点击 `导出` 按钮后，在按钮下方展开小面板，包含：

- `复制文本`
- `导出 TXT`
- `导出 Markdown`

交互要求：

- 再次点击 `导出` 可收起
- 点击 dropdown 外部区域自动收起
- 点击其中一项后执行动作并收起

### 片段卡片

片段默认只展示：

- 时间
- 文本
- 状态标签
- 疑似错误标签

审核操作默认隐藏。

当鼠标 hover 到片段卡片时，才在卡片右下或底部右侧出现：

- `确认`
- `修正`

状态规则：

- `pending`
  - hover 时显示 `确认`、`修正`
- `confirmed`
  - 默认显示 `已确认`
  - hover 时仅显示 `修正`
- `corrected`
  - 默认显示 `已修正`
  - hover 时显示 `再修正`

编辑态例外：

- 点击 `修正` 后，片段展开 textarea
- 此时 `保存 / 取消` 常驻显示，不依赖 hover

## 视觉设计

### 功能分层

- `查看` 维持冷色系
- `导出` 作为单独主入口，用暖色但更收敛的强调色
- `未处理 X` 保持信息胶囊样式，不伪装成按钮

### 空间策略

- 顶部统一使用更小的胶囊按钮
- 片段操作改为 text-like 的轻按钮
- 减少重复文案长度，更多依赖 tooltip

## 代码组织

### `index.html`

需要调整：

- 顶部工具区 DOM 结构
- 新增导出 dropdown 容器
- 片段 hover 操作所需样式

### `renderer.js`

需要新增：

- dropdown 开关状态
- 点击外部关闭 dropdown
- 导出动作迁移到 dropdown 项目
- 片段 hover 操作对应的类与事件

## 边界情况

### 没有任务或没有文本

- `导出` 按钮和查看切换保持隐藏

### 当前没有未处理片段

- `未处理 X` 显示为 0
- `重点 / 未处理` 过滤仍可切换，但进入后显示空状态

### 片段进入编辑态

- 当前片段的操作区切换成 `保存 / 取消`
- 其他片段保持默认展示

## 验收标准

1. 顶部工具区可见按钮数量明显减少
2. `导出` 点击后展开 dropdown，包含 `复制文本 / 导出 TXT / 导出 Markdown`
3. 点击 dropdown 外部区域后可自动收起
4. `清洗 / 原始 / 全部 / 重点 / 未处理 / 未处理 X` 继续正常工作
5. 片段默认不显示 `确认 / 修正`
6. hover 到片段时，才出现 `确认 / 修正`
7. `confirmed` 状态 hover 只显示 `修正`
8. `corrected` 状态 hover 显示 `再修正`
9. 点击 `修正` 后，当前片段展开编辑态，显示 `保存 / 取消`
10. `npm run smoke` 通过，前端脚本语法检查通过
